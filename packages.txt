# Packages of this bitweaver fork, one per line: name, group, then the packages it needs.
#
#   core      always fetched: bitweaver does not run without these
#   default   fetched when no package is named: a basic site (wiki and image galleries)
#   optional  fetched only when named on the command line (get-packages.sh blogs search)
#
# "needs" is what each package declares itself with registerRequirements() in admin/schema_inc.php, so
# naming a package also fetches what it needs. A package that declares nothing is marked "(none declared)".
# config/ and storage/ are part of this wrapper repository itself and need no fetch.
#
